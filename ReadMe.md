Student Management System API

Student Management System API is RESTful API built with Node.js and Express.js that allows an institution to manage students, departments, courses and course registrations.

FEATURES

Student Management: Create, retrieve, update, and delete student records.

Department Management: Create, retrieve, update, and delete academic departments.

Course Management: Create, retrieve, update, and delete courses.

Student-Department Assignment: Assign students to academic departments.

Course Registration: Allow students to register for multiple courses.

Student Course Retrieval: Retrieve all courses registered by a particular student.

Department Student Retrieval: Retrieve all students belonging to a particular department.

Input Validation: Validate incoming data using Joi.

TECHNOLOGIES USED

Node.js
Express.js
JavaScript (common js)
Sequelize ORM
Joi validation 
Mysql database


REQUIRMENTS

Before running the project, ensure you have installed:

Node.js (which includes npm)

Postman or another API client for testing

mysql workbench

sequelize orm

INSTALLATION AND SETUP

Clone the repository

git clone https://github.com/abahVictony/Student_Management_System.git

Navigate into the project directory:
cd Student Management System API

Install dependencies

npm install Or npm i

Run the project

npm run dev
